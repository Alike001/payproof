# PayProof External Testing Log

Use one entry per recruited person. Do not record names, phone numbers, email
addresses, private keys, recovery phrases, IP addresses, or private messages.
Public invoice references, public Base Sepolia transaction hashes, and public
wallet addresses may be linked as verification evidence.

The project team and its controlled wallets are internal activity. A teammate
testing their own project is not labelled as an outside user.
